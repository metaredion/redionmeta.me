## Overview

**[redionmeta.me](https://redionmeta.me)** is my personal hub for **cybersecurity & penetration testing**, **AI & business workflow automation**, **custom web platforms**, and **network engineering** — built around a fast, minimalist command-line experience in both the browser and terminal (`curl -sL redionmeta.me`).

## Highlights

- **Empty-on-Load Interactive Shell:** Opens directly to a live `$` prompt with `Tab` autocomplete, command history, and one-click command chips:
  - `projects` — Showcase catalog (with category filters on `/projects/`)
  - `telegram` / `jobs` / `rentals` — Live curated Telegram alert channels
  - `automations` — Personalized business & workflow automation inquiries
  - `website` — Personalized websites, portals & custom web platforms
  - `pentest` — Authorized penetration testing & security assessment inquiries
  - `ctf` — Capture The Flag tracks & team invitations
  - `contact` & `msg <email> <text>` — Send a message straight to my inbox from the terminal
  - `star` / `whoami` / `fastfetch` / `theme` / `clear`
- **Category-Filtered Projects Page (`/projects/`):** Filter live products across **Automations**, **Telegram Channels**, **Cloud & Linux**, and **Web**.
- **Native Terminal Card:** Running `curl -sL redionmeta.me` in any terminal prints a clean ANSI summary card.
- **Direct Inbox Contact (`/contact/`):** Instant email form alongside direct GitHub and LinkedIn links.
